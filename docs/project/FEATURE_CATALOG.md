# Feature Catalog

- **Dashboard:** Activity counters, EOD reports, pending requests lists, task boards.
- **Inbox Alerts:** HierarchyRequest logs, standard notifications, and direct actions.
- **Team Chat:** WebSocket-based messaging with audio/sound alerts and online state.
- **Point of Sale (POS):** Barcode search, discount calculations, payment configuration, and quick sizing tool.
- **Inventory Manager:** SKU tables, low stock thresholds, and purchase request submission.
- **Pump Catalog:** Mechanical specifications, accessories lists, and flow-head scatter charts.
- **Pump Sizing Calculator:** Input sizing factors, reverse-geocoding Leaflet map, curve comparison, and PDF proposal generation.
- **Finance Center:** Sectioned tab lists for Cash Flow, Balance Sheets, Ledger entries, VAT calculations, and Peachtree integrations.
- **HR & Attendance:** Fingerprint register, attendance checker, and registry reports.
